Fundamentos de Diseño

Abstracción Comprobada

Los patrones de diseño son soluciones conceptuales probadas a problemas recurrentes en el software orientado a objetos.

Vocabulario Común

Permiten que el equipo técnico se comunique mediante conceptos arquitectónicos estandarizados, reduciendo la ambigüedad.

1. Adapter Pattern

Estructural: Actúa como un envoltorio (wrapper). Permite que objetos con interfaces incompatibles colaboren.

Ideal para integrar APIs de terceros o sistemas heredados sin alterar el código fuente original.

// Interface Target interface Target { request(): string; } // Bridge Implementation class Adapter implements Target { constructor(private adaptee: Adaptee) {} request() { return this.adaptee.specificRequest(); } }

2. Builder Pattern

Creacional: Separa la construcción de un objeto complejo de su representación final.

Evita constructores con demasiados parámetros, delegando la creación paso a paso a un objeto Builder.

// Fluent Interface const house = new HouseBuilder() .buildWalls(4) .buildRoof("Gable") .hasGarage(true) .getResult();

Visualización: Builder

El Director ordena la secuencia: Base $\rightarrow$ Columnas $\rightarrow$ Techo.

Auto-construcción sistemática. La complejidad de ensamblaje queda oculta tras una interfaz de construcción simple.

3. Iterator Pattern

Comportamiento: Acceso secuencial a elementos de una colección sin exponer su estructura interna.

Permite recorrer árboles, grafos o listas usando la misma interfaz: next() y current().

// Universal Access while (iterator.valid()) { console.log(iterator.current()); iterator.next(); }

Ingeniería Estructurada

La correcta aplicación de patrones reduce la deuda técnica y aumenta la mantenibilidad del sistema.
